## 🧩 About

**Deep Rock Galactic Companion** is a curated list of Deep Rock Galactic open-source tools:

- **Overlays** — on-screen helpers, layout notes, cave map viewer, depth tracker
- **Quality-of-Life Helpers** — mineral catalog, class notes, overlay notes

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Cave Map Notes — review tunnel layouts from any checkpoint
- Resource Tracker — visualize ore and mineral positions in study mode
- Route Notes — record and review mission paths
- Playback Speed — adjust study playback for walkthroughs (0.1x to 5x)

### Wallhack
- Class Catalog — browse classes, armor, and pickaxe skins
- Custom Loadout Notes — organize dwarf cosmetics
- Visibility Notes — improved terrain readability for study

### Aimbot
- Practice Mode Notes — segment study on any mission type
- Gravity Flip Control — manually switch gravity in the sandbox
- Jump Buffer Notes — chain complex maneuvers in the editor
